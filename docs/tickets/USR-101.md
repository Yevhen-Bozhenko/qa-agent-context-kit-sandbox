# USR-101 — Validate new users

**Type:** Story · **Status:** Done (in production)

## Acceptance criteria

1. `email` is required and must be a valid email address.
2. `name` is required and at most 100 characters long.
3. When a request violates any rule, the API responds `400` with
   `{ "code": "VALIDATION_ERROR", "errors": [{ "field", "message" }] }`, one entry per invalid field.
4. Valid requests are accepted with `201`.
